# gnoweb Connected Reads — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a connected gnoweb visibly different from a disconnected one: explain a `signer_unavailable` decline, show balance/account/username for the connected address, fill the gnokey command, offer the address on `address` parameters, and badge the address in realm content.

**Architecture:** Everything runs client-side against the RPC in `<meta name="gnoconnect:rpc">`, the same way `_fetchQEval` already does. A new `chain.ts` (RPC helper) and `account.ts` (per-address loader with a page-wide cache) feed thin consumers in the existing controllers. A read failure always degrades to today's disconnected page.

**Tech Stack:** TypeScript compiled by esbuild into `public/js/`, Go `html/template`, PostCSS/Cube CSS, biome, Node's built-in test runner (`node --test`, no new dependency), testify for Go tests.

**Spec:** `docs/superpowers/specs/2026-09-29-gnoweb-connected-reads-design.md`. Read it first; the plan argues from it. Background: `docs/superpowers/specs/2026-09-22-gnoconnect-demo-usecase-brainstorm.md`.

## Global Constraints

- Paths are relative to the repo root. gnoweb is `gno.land/pkg/gnoweb/` (below: `GW/`).
- **Commits:** conventional, one per task, always signed off: `git commit -s -m "..."`. No `Co-Authored-By`, `Assisted-By` or "Generated by" trailers.
- **Comments:** one-line comments, short function docs; rationale goes in the ADR (Task 10).
- **Built assets are committed.** After any `.ts`/`.css`/template change run `make -C GW generate` and `git add GW/public/`. CI (`gnoweb_generate`) fails when `public/` is stale.
- **Formatting/lint:** `make -C GW/frontend fmt` then `make -C GW/frontend lint` must pass; Go with `gofmt` and `go vet`.
- **Untrusted input is never rendered as HTML.** Realm text, URL parameters, usernames and denoms go through `textContent` / `encodeURIComponent`; `code` from the URL is matched, never displayed; denom strings are never displayed at all.
- **Every read failure degrades silently** to today's disconnected rendering, logged through `this.warn` with the query path only.
- **Addresses spliced into an expression or a query path must pass `isAddress`** (`/^g1[02-9ac-hj-np-z]{38}$/`) first; anything else sends no request.
- **Bundle boundary:** every `.ts` under `GW/frontend/js/` and `GW/feature/*/frontend/` compiles to its own bundle; only `controller.js` is shared. Module-level state is therefore **per bundle** — cross-controller state goes through `window` events or a `globalThis[Symbol.for(...)]` slot.
- Session storage key stays `gnoweb:session:v1`; the new `username` field is optional.
- Browser checks use the Chrome plugin (both themes, phone width ≈ 390px).
- Run `/simplify` before presenting completed work.

## Review Focus

1. **A `$help` page with dozens of functions** (boards2 has ~40) must send **one** `auth/accounts` request per address change, not one per function block. → Task 5 test "concurrent loads share one request"; Task 6 routes the tab-return refresh through the single `action-header` instance.
2. **Typing quickly in the ADDRESS field** must end with the numbers of the *last* address, not whichever response arrived last. → Task 6 guard `this._address !== address` plus browser step 8.
3. **A key name, an uppercase address, or a half-typed address in the ADDRESS field** must keep the placeholders and send **no** request. → Task 5 test "loadAccount rejects non-addresses without a request".
4. **An account holding junk or many denoms** (`"5ugnot,1<script>,10foo/bar,..."`) must still show the GNOT balance and a count, never a denom string, never throw. → Task 5 test "junk denoms are counted, never kept".
5. **An address that is both a link's text and its `href`** gets exactly one badge; an address inside a code block gets none. → Task 9 pure tests plus the throwaway `badgecheck` realm in step 6.

## Assumptions and deviations from the spec

Found while reading the code for this plan; Task 10 records them in the spec.

1. **Session changes do not cross bundles today.** `controller-connect.js` and `controller-wallet-launch.js` each embed their own `session.ts`, so `onSessionChange` only hears writes from its own bundle. Task 2 (new, not in the spec) moves notification to a `window` event. The account cache likewise lives in a `globalThis[Symbol.for("gnoweb.account.cache")]` slot.
2. **The cache is not cleared on session change.** It is keyed by address, so a new identity never reads the old entry; clearing would only add a subscription.
3. **`abciQuery` returns text, not bytes.** Every consumer parses JSON.
4. **`func` comes from the `$help&func=…` web query in the URL path**, not the query string (see `weburl.Parse(...).WebQuery` in `GW/components/view_action_test.go`), with a query-string fallback for the static fixture.
5. **The "me" button is rendered server-side** only for `address`/`.uverse.address` params, instead of exposing every param's type as an attribute. Fewer bytes, same rule.
6. **`you-badge` mounts on a hidden sentinel in `realm.html`** and finds `md-renderer` itself. `BaseController` reads its name from the whole `data-controller` attribute, so two controllers on one element break `getTarget`/`getValue`, and wrapping `md-renderer` in a `div` would break the aside/article grid.

```ts
// Browser globals for unit tests. Importing this module installs a default
// DOM, because some modules (wallet-discovery.ts) touch window on load.

export interface FakeDOM {
	storage: Map<string, string>;
	metas: Record<string, string>;
}

export function installDOM(metas: Record<string, string> = {}): FakeDOM {
	const storage = new Map<string, string>();
	const localStorage = {
		getItem: (key: string) => storage.get(key) ?? null,
		setItem: (key: string, value: string) => {
			storage.set(key, value);
		},
		removeItem: (key: string) => {
			storage.delete(key);
		},
	};
	const win = Object.assign(new EventTarget(), { localStorage });
	const doc = Object.assign(new EventTarget(), {
		querySelector: (selector: string) => {
			const match = /^meta\[name="([^"]+)"\]$/.exec(selector);
			const content = match ? metas[match[1]] : undefined;
			if (content === undefined) return null;
			return {
				getAttribute: (name: string) => (name === "content" ? content : null),
			};
		},
	});
	Object.assign(globalThis, { window: win, document: doc });
	return { storage, metas };
}

export interface FakeResponse {
	status?: number;
	body: unknown;
}

// stubFetch replaces fetch with a handler and returns the requested URLs.
export function stubFetch(
	handler: (url: string) => FakeResponse | Error,
): string[] {
	const calls: string[] = [];
	globalThis.fetch = (async (input: string | URL | Request) => {
		const url = input instanceof Request ? input.url : String(input);
		calls.push(url);
		const res = handler(url);
		if (res instanceof Error) throw res;
		return new Response(JSON.stringify(res.body), {
			status: res.status ?? 200,
		});
	}) as typeof fetch;
	return calls;
}

// abciBody is an abci_query JSON-RPC answer: base64 Data, or a node Error.
export function abciBody(data: string | null, error?: string): unknown {
	return {
		jsonrpc: "2.0",
		id: "",
		result: {
			response: {
				ResponseBase: {
					Error: error ? { "@type": "/abci.StringError", value: error } : null,
					Data: data === null ? null : btoa(data),
					Events: null,
					Log: "",
					Info: "",
				},
			},
		},
	};
}

installDOM();
```

```ts
// Client-side reads against the RPC the page advertises in
// <meta name="gnoconnect:rpc">. Callers degrade on ChainError.

export class ChainError extends Error {
	// nodeError is the node's own error value; unset for transport failures.
	constructor(
		message: string,
		readonly nodeError?: string,
	) {
		super(message);
		this.name = "ChainError";
	}
}

interface AbciEnvelope {
	result?: {
		response?: {
			ResponseBase?: { Error?: { value?: string } | null; Data?: string | null };
		};
	};
}

export function readMeta(name: string): string {
	return (
		document
			.querySelector(`meta[name="${name}"]`)
			?.getAttribute("content")
			?.trim() ?? ""
	);
}

export function normalizeRPC(raw: string): string | null {
	const value = raw.trim();
	if (!value) return null;
	const url = /^[a-z][a-z0-9+.-]*:\/\//i.test(value) ? value : `http://${value}`;
	return url.replace(/\/+$/, "");
}

export function rpcURL(): string | null {
	return normalizeRPC(readMeta("gnoconnect:rpc"));
}

function toHex(text: string): string {
	return Array.from(new TextEncoder().encode(text), (b) =>
		b.toString(16).padStart(2, "0"),
	).join("");
}

function fromBase64(data: string): string {
	return new TextDecoder().decode(
		Uint8Array.from(atob(data), (c) => c.charCodeAt(0)),
	);
}

// abciQuery returns the response Data as text, or null when there is none.
export async function abciQuery(
	path: string,
	data?: string,
	remote: string | null = rpcURL(),
): Promise<string | null> {
	if (!remote) throw new ChainError("no RPC endpoint on this page");
	let url = `${remote}/abci_query?path=${encodeURIComponent(path)}`;
	if (data !== undefined) url += `&data=0x${toHex(data)}`;

	let body: AbciEnvelope;
	try {
		const response = await fetch(url);
		if (!response.ok) throw new ChainError(`${path}: HTTP ${response.status}`);
		body = (await response.json()) as AbciEnvelope;
	} catch (err) {
		if (err instanceof ChainError) throw err;
		throw new ChainError(`${path}: ${String(err)}`);
	}

	const base = body?.result?.response?.ResponseBase;
	if (!base) throw new ChainError(`${path}: malformed response`);
	if (base.Error) {
		const value = base.Error.value ?? "query failed";
		throw new ChainError(`${path}: ${value}`, value);
	}
	return base.Data ? fromBase64(base.Data) : null;
}

// qevalJSON evaluates expr and returns its first result as a string.
export async function qevalJSON(expr: string): Promise<string> {
	const text = await abciQuery("vm/qeval_json", expr);
	try {
		const value = JSON.parse(text ?? "")?.results?.[0]?.V?.value;
		if (typeof value === "string") return value;
	} catch {
		// fall through
	}
	throw new ChainError(`vm/qeval_json: no string result for ${expr}`);
}
```

```ts
import { truncate } from "../../feature/connect/frontend/session.js";

export const SIGNER_UNAVAILABLE = "signer_unavailable";

// helpFunc is the function a help URL targets: `$help&func=X` in the path,
// or `?func=X` on the static fixture.
export function helpFunc(url: URL): string {
	const at = url.pathname.indexOf("$");
	if (at >= 0) {
		const func = new URLSearchParams(url.pathname.slice(at + 1)).get("func");
		if (func) return func;
	}
	return url.searchParams.get("func") ?? "";
}

// outcomeMessage is the notice for funcName, or null when the URL has none.
export function outcomeMessage(
	href: string,
	funcName: string,
	address: string | null,
): string | null {
	const url = new URL(href);
	if (url.searchParams.get("status") !== "error") return null;
	if (url.searchParams.get("code") !== SIGNER_UNAVAILABLE) return null;
	if (!funcName || helpFunc(url) !== funcName) return null;
	return address
		? `Your wallet isn't on ${truncate(address)}, the account you're connected as. Switch to it in the wallet, or reconnect.`
		: "Your wallet isn't on the account you connected with. Switch to it in the wallet, or reconnect.";
}

export function withoutOutcome(href: string): string {
	const url = new URL(href);
	url.searchParams.delete("status");
	url.searchParams.delete("code");
	return url.toString();
}
```

```ts
import { abciQuery, ChainError, qevalJSON, readMeta } from "./chain.js";

// Per-address chain data for the connected account, cached for the page and
// shared by every controller bundle through a globalThis slot.

export interface Account {
	address: string;
	accountNumber: string; // decimal strings: uint64 exceeds Number
	sequence: string;
	ugnot: bigint;
	otherDenoms: number; // counted only; denom strings are never displayed
}

const ADDRESS = /^g1[02-9ac-hj-np-z]{38}$/;
const COIN = /^(\d+)([a-z][a-z0-9/:._-]{1,127})$/;
const CACHE = Symbol.for("gnoweb.account.cache");

export function isAddress(s: string): boolean {
	return ADDRESS.test(s);
}

function cache(): Map<string, Promise<unknown>> {
	const slot = globalThis as unknown as Record<symbol, Map<string, Promise<unknown>> | undefined>;
	slot[CACHE] ??= new Map();
	return slot[CACHE];
}

function cached<T>(key: string, load: () => Promise<T>): Promise<T> {
	const entries = cache();
	let promise = entries.get(key) as Promise<T> | undefined;
	if (!promise) {
		promise = load();
		entries.set(key, promise);
		promise.catch(() => entries.delete(key));
	}
	return promise;
}

export function refresh(address: string): void {
	cache().delete(`account:${address}`);
}

export function parseAccount(address: string, text: string | null): Account | null {
	if (text === null) return null;
	let base: { coins?: string; account_number?: string; sequence?: string } | undefined;
	try {
		base = JSON.parse(text)?.BaseAccount;
	} catch {
		throw new ChainError(`auth/accounts/${address}: unreadable account`);
	}
	if (!base) return null;

	let ugnot = 0n;
	let otherDenoms = 0;
	for (const coin of (base.coins ?? "").split(",")) {
		const match = COIN.exec(coin.trim());
		if (!match) continue;
		if (match[2] === "ugnot") ugnot += BigInt(match[1]);
		else otherDenoms++;
	}
	return {
		address,
		accountNumber: String(base.account_number ?? "0"),
		sequence: String(base.sequence ?? "0"),
		ugnot,
		otherDenoms,
	};
}

export function formatGnot(ugnot: bigint): string {
	const whole = (ugnot / 1_000_000n).toLocaleString("en-US");
	const frac = ugnot % 1_000_000n;
	if (frac === 0n) return `${whole} GNOT`;
	return `${whole}.${frac.toString().padStart(6, "0").replace(/0+$/, "")} GNOT`;
}

export function accountView(account: Account | null): { balance: string; line: string | null } {
	if (!account) return { balance: "0 GNOT · not on chain yet", line: null };
	const n = account.otherDenoms;
	const extra = n === 0 ? "" : ` · +${n} other token${n === 1 ? "" : "s"}`;
	return {
		balance: `${formatGnot(account.ugnot)}${extra}`,
		line: `Account ${account.accountNumber} · Sequence ${account.sequence}`,
	};
}

export function commandNumbers(account: Account | null): { accountNumber: string; sequence: string } {
	return account
		? { accountNumber: account.accountNumber, sequence: account.sequence }
		: { accountNumber: "ACCOUNTNUMBER", sequence: "SEQUENCENUMBER" };
}

// chainMatches is false only when the session and the page name different chains.
export function chainMatches(sessionChainid: string): boolean {
	const page = readMeta("gnoconnect:chainid");
	return !sessionChainid || !page || sessionChainid === page;
}

export function loadAccount(address: string): Promise<Account | null> {
	if (!isAddress(address)) return Promise.reject(new ChainError("not an address"));
	return cached(`account:${address}`, async () =>
		parseAccount(address, await abciQuery(`auth/accounts/${address}`)),
	);
}

// loadUsername is null for an unregistered address; an RPC failure throws.
export function loadUsername(address: string): Promise<string | null> {
	if (!isAddress(address)) return Promise.reject(new ChainError("not an address"));
	return cached(`username:${address}`, async () => {
		try {
			const name = await qevalJSON(`gno.land/r/sys/users.ResolveAddress("${address}").Name()`);
			return name || null;
		} catch (err) {
			// The node evaluated and failed: a nil *UserData, i.e. not registered.
			if (err instanceof ChainError && err.nodeError !== undefined) return null;
			throw err;
		}
	});
}
```

```ts
// Caps the text walk on huge realm pages.
export const MAX_TEXT_NODES = 5000;

// linkIsSelf reports whether href points at the connected identity.
export function linkIsSelf(
	href: string,
	base: string,
	address: string,
	username?: string,
): boolean {
	let url: URL;
	try {
		url = new URL(href, base);
	} catch {
		return false;
	}
	if (username && url.origin === new URL(base).origin) {
		if (decodeURIComponent(url.pathname) === `/u/${username}`) return true;
```

```ts
import { readSession } from "../../feature/connect/frontend/session.js";
import { isAddress } from "./account.js";
import { BaseController } from "./controller.js";
import { linkIsSelf, MAX_TEXT_NODES } from "./you-badge.js";

// YouBadgeController marks the connected address where a realm renders it.
// It inserts its own element only; realm text is never re-parsed.
export class YouBadgeController extends BaseController {
	protected connect(): void {
		const session = readSession();
		const root = document.querySelector("md-renderer");
		if (!session || !root || !isAddress(session.address)) return;
		const { address, username } = session;

		const links: Element[] = [];
		root.querySelectorAll("a[href]").forEach((a) => {
			if (a.closest("pre, code")) return;
			if (linkIsSelf(a.getAttribute("href") ?? "", window.location.href, address, username)) {
				links.push(a);
			}
		});

		const texts: Text[] = [];
		const walker = document.createTreeWalker(root, NodeFilter.SHOW_TEXT);
		for (let i = 0; i < MAX_TEXT_NODES; i++) {
			const node = walker.nextNode() as Text | null;
			if (!node) break;
			// Links are badged once, above; code shows data, not people.
			if (node.parentElement?.closest("pre, code, a")) continue;
			if (node.data.includes(address)) texts.push(node);
		}

		links.forEach((a) => a.after(badge()));
		texts.forEach((node) => {
			node.splitText(node.data.indexOf(address) + address.length);
			node.after(badge());
		});
	}
}

function badge(): HTMLElement {
	const el = document.createElement("span");
	el.className = "b-you";
	el.textContent = "you";
	return el;
}
```

- [ ] **Step 1: ADR section**

Insert before `## Alternatives considered`:

```markdown
### Connected reads run in the browser

A connected page reads the account (`auth/accounts`), the username
(`vm/qeval_json` on `r/sys/users.ResolveAddress(addr).Name()`) from the RPC in
`gnoconnect:rpc`, as `_fetchQEval` already did for `$help` results. The address
never reaches the gnoweb server and pages stay identical for every visitor. The
loader is keyed by address (the `$help` ADDRESS field may differ from the
session) and cached per page in a `globalThis` slot, because every controller
bundle embeds its own modules. The username may be stored in the session entry
to avoid a flash on navigation; balance and sequence never are. Session changes
travel as a `window` event for the same bundle reason. Any read failure renders
today's disconnected page.
```

Append to `## Alternatives considered`:

```markdown
- **Server-side reads** (new gnoweb endpoints over `gnoclient`): no RPC reachability
  concerns, but gnoweb would learn who is connected and per-user responses break caching.
- **One fetch per controller**: duplicates `auth/accounts` per function block on `$help`.
- **`@gnolang/gno-js-client` for encoding** (future dry-run): imports Node `crypto` and
  bundles to 326 KB minified; a hand-written encoder is planned instead.
```

## Demo: GnoConnect on gnoweb

A 6–8 minute walkthrough showing what `connect()` gives a dapp. The story:
**a disconnected gnoweb is a form; a connected one knows who you are and says so.**

### Setup (once, before the audience)

1. **Two Adena accounts** in the dev build (`/Users/remi/adena-wallet/packages/adena-extension/dist`, enabled; disable the store Adena so only the announcing wallet injects). Account **A** will be funded; account **B** is any other account.
2. **Build and start gnodev from this worktree** (its `go.mod` replaces gno with `../..`, so it embeds this branch's gnoweb):

   ```bash
   make -C gno.land/pkg/gnoweb generate
   go -C contribs/gnodev run . \
     -paths gno.land/r/sys/namereg/v0,gno.land/r/demo/defi/foo20,gno.land/r/gnoland/coins \
     -add-account <address of A>=100000000000ugnot \
     -web-help-remote http://127.0.0.1:26657
   ```

   `namereg/v0` **must** be in `-paths`: it registers itself as a username controller only at genesis (`examples/gno.land/r/sys/namereg/v0/init.gno`).
3. **Adena network:** add a custom network, chain ID `dev`, RPC `http://127.0.0.1:26657`; select it.
4. **Clean state:** open `http://127.0.0.1:8888`, disconnect if connected, and clear `localStorage` key `gnoweb:session:v1`.
5. **Tabs, in order:**
   - T1 `http://127.0.0.1:8888/r/demo/defi/foo20$help`
   - T2 `http://127.0.0.1:8888/r/sys/namereg/v0$help`
   - T3 `http://127.0.0.1:8888/r/gnoland/coins:balances?address=<address of A>`
   - a terminal with `gnokey` and A's key imported (optional, for step 5)
6. Rehearse once; account A's sequence then moves, which is fine.

### Script

**1. Before connecting (T1) — 30 s.** Mode *Secure*. Point at the command: `ADDRESS`, `ACCOUNTNUMBER`, `SEQUENCENUMBER`. "Today you look these up by hand."

**2. Connect — 30 s.** Header → *Connect* → Adena approves. The header shows the avatar and `g1…`. The ADDRESS field and every command now carry A's address, and account number and sequence are filled. "One `connect`, and the copy-paste command is complete."

**3. The identity menu — 30 s.** Open the avatar menu: full address, **GNOT balance**, account number and sequence. "The three numbers you check when a transaction fails."

**4. "me" on address parameters (T1) — 45 s.** `BalanceOf` → **me** on `owner`: the live result shows A's foo20 balance (0). Execute `Faucet` through Adena; back on the page, `BalanceOf` → **me** again: the balance moved. Point at the command: the **sequence went up by one** by itself.

**5. (Optional) Terminal round trip — 45 s.** Copy the *Secure* command for `Faucet`, run it in the terminal, switch back to the tab: the sequence is already the next one (refreshed when the tab became visible).

**6. A name instead of a hash (T2) — 60 s.** `Register` → `username` = `nym-demouser123` → Execute → approve. On the landing page the header reads **`@nym-demouser123`**; the menu has a link to `/u/nym-demouser123`. "Resolved from `r/sys/users` in the browser — gnoweb's server never learns who you are."

**7. "you" in realm content (T3) — 30 s.** Reload T3: the coins realm renders your name, marked **you**. "Any realm that shows your address or your `/u/` link gets this, with no realm change."

**8. The signer pin, made visible — 60 s.** In Adena, switch to account **B** without touching gnoweb (the header still says `@nym-demouser123`). T1 → Execute `Faucet`. The wallet declines because gnoweb pinned A as `signer`; gnoweb shows: *"Your wallet isn't on g1…, the account you're connected as. Switch to it in the wallet, or reconnect."* Click **Reconnect** → the chooser opens. "Without the pin the wallet would have signed as B."
   - If the Adena dev build does not enforce the pin, show the same notice with the fixture instead: `http://localhost:8000/frontend/fixtures/wallet-connect.html?stub=wrongsigner` (served by `python3 -m http.server 8000` from `gno.land/pkg/gnoweb`) → Connect → Execute.
   - The launch-link path lands on the same notice: open `http://127.0.0.1:8888/r/demo/defi/foo20$help&func=Faucet?status=error&code=signer_unavailable`.

**9. Graceful degradation — 30 s.** Disconnect: every addition disappears, the page is exactly today's gnoweb. Optionally stop gnodev's RPC and reconnect: the header and "me" still work, the balance and numbers simply don't appear, nothing errors.

### Fallbacks during the demo

- **Name already taken** in step 6: use another `nym-<5–13 letters><3 digits>`.
- **Wallet shows another network**: re-select `dev` in Adena, then Change wallet in the header.
- **Nothing shows in the menu**: check `<meta name="gnoconnect:rpc">` in the page source — it must be `127.0.0.1:26657` (set by `-web-help-remote`).
